本文档说明 A 股界面中「策略族」各选项的含义、主要参数、适用场景与注意事项。内容依据：

- `src/strategies/ashare_strategy_runner.py` 中的 `STRATEGY_FAMILIES`、`USE_CASE_PRESETS`
- 项目根目录 `README.md`（A 股策略与 FinRL 滚动 DRL 小节、Use Case 1–3）
- `A股改造说明.md` §6.2 策略族与参数

不编造未在上述来源中出现的能力。

| 预设 | 默认策略族 | 说明 |
|:---|:---|:---|

| 用例2·滚动选股+DRL | `ml_then_drl` | README Use Case 2：ML 滚动选股后再 DRL 定权；预设常带 `prediction_mode=rolling`、`weight_method=equal`、`drl_algo=ppo` |

## 策略族一览

### `equal_weight` — 等权

- **做什么**：股票池内每只股票权重相同（1/N）。
- **实现**：原 `EqualWeightStrategy`。
- **主要参数**：无特殊组合优化参数；依赖基本面/股票池名单。
- **何时用**：基线配置、快速试通数据与执行链路；用例1默认。

### `min_variance` — 最小方差（经典，全池）

- **做什么**：用全池历史收益的协方差，最小化组合波动。
- **实现**：`classical_min_variance`（scipy，做多约束、权重和为 1）。
- **主要参数**：`lookback_periods`（回看期，界面常用默认约 252 个交易日）。
- **何时用**：希望降低波动的经典配置；需要价格面板。

### `mean_variance` — 均值方差 / 最大夏普（经典，全池）

- **做什么**：在全池上做均值-方差优化，目标为最大夏普（做多约束）。
- **实现**：`classical_mean_variance`（scipy）。
- **主要参数**：`lookback_periods`。
- **何时用**：用例1中的经典配置对照；需要价格面板。

### `market_cap` — 市值加权（通达信 gbbq）

- **做什么**：市值 = 收盘价 × 通达信 gbbq 股本（万股）× 10000；再按市值比例定权。
- **主要参数**：`mv_field`：`total_mv`（总市值）或 `circ_mv`（流通市值）；依赖通达信目录下 `T0002/hq_cache/gbbq`。
- **何时用**：要贴近市值加权基准式持仓时。

### `ml` — ML 选股（MLStockSelectionStrategy）

- **做什么**：机器学习基本面选股，再按权重方法给出组合权重。
- **主要参数**（界面可调）：`prediction_mode`（`single` / `rolling`）、`weight_method`（如 `min_variance` / `equal`）、`train_quarters`、`test_quarters`、`top_quantile`、`confirm_mode`、`lookback_periods`。
- **何时用**：要做基本面 ML 选股、且不强制行业中性时。

### `sector_neutral_ml` — 行业中性 ML（SectorNeutralMLStrategy）

- **做什么**：按行业（`gsector`）分别训练再合并；自动 `with_industry=True`，缓存前缀常加 `_ind`。
- **主要参数**：与 `ml` 相同的 ML 参数集。
- **何时用**：希望控制行业暴露、需要行业映射数据时。

### `ml_bucket` — 分桶 ML（A股行业映射四桶）

- **做什么**：美股原项目有 GICS 四桶思路；**A 股无该原始四桶数据**，此处按行业中性路径落地（与行业中性相近）。
- **主要参数**：同 ML 参数；需要 `gsector`。
- **何时用**：想沿用「分桶」标签、实际走行业中性落地时。

### `drl` — 短训 DRL 配置

- **做什么**：用 `ashare_drl_runner` 在较短训练步数下生成配置权重；优先 stable-baselines3，否则可用 torch 路径。
- **主要参数**：`drl_algo`（`ppo` / `a2c` / `ddpg`）、`drl_timesteps`（界面默认约 8000）、`lookback_periods`、`drl_epochs`、`drl_top_n` 等。
- **何时用**：用例1中可选的「短训 DRL」；要比完整滚动训推快得多。**不是** `finrl_rolling_drl`。

### `ml_then_drl` — 滚动 ML 选股 + DRL 定权

- **做什么**：先 ML（常用 rolling）选出股票，再用短训 DRL 定权；对应 README 用例2。
- **主要参数**：ML 参数 + `drl_algo` 等短训 DRL 参数。
- **何时用**：要「选股 + 学习定权」组合、又不想跑完整 FinRL 滚动时。

### `finrl_rolling_drl` — FinRL 滚动 DRL（完整训推）

- **做什么**：完整复制原项目滚动流程：构建 OHLCV 面板 → 技术指标与协方差特征 → 按季/月再平衡窗口训练多算法（A2C/PPO/DDPG，可选 TD3/SAC）→ 测试窗选优 → 交易窗推理权重；模型与结果可落盘到 `artifacts/ashare_drl/`（含 `progress.json`，可续跑）。
- **主要参数（界面）**：算法多选、再平衡频率（`Q`/`M`）、`max_windows`、`max_stocks`、各算法 timesteps、是否 resume、输出目录等。
- **何时用**：要复现完整 FinRL 滚动训推、并接受长时间计算时。
- **重要**：**非常慢**。多窗 × 多算法 × 每算法数万步；网页长跑易被 Streamlit 刷新打断。首次建议 `max_stocks` 很小、`timesteps` 很小、`max_windows=1` 试跑；正式长跑优先用命令行 `python -m src.ashare_finrl_cli`（可 `--resume`）。短训请改选 `drl`。

### `adaptive_rotation` — 自适应多资产轮动

- **做什么**：对接原 Adaptive Multi-Asset Rotation；A 股侧用代理指数与行业分组写出 `AdaptiveRotationConf_ashare.yaml` 与日线 CSV（`^GSPC` / `^VIX` / `QQQ` 为 A 股代理），再调用原引擎。
- **依赖**：PyYAML。
- **何时用**：README 用例3；研究向轮动与风险监控流程。

### `custom` — 自定义策略（Python 类路径）

- **做什么**：加载用户指定的 `.py` 文件中继承 `BaseStrategy` 的类，调用 `generate_weights(data, **kwargs)`，返回含 `tic`/`weight` 的权重。
- **主要参数**：文件路径、可选类名（空则取文件中第一个子类）。示例：`examples/ashare_custom_strategy_example.py`。
- **何时用**：自有规则/模型已写成策略类，要接入同一套数据与执行入口时。

## `drl` 与 `finrl_rolling_drl` 对照

| | `drl`（短训） | `finrl_rolling_drl`（完整滚动） |
|:---|:---|:---|
| 入口 | `ashare_drl_runner` | `ashare_finrl_drl` |
| 训练规模 | 默认约数千步量级 | 多再平衡窗 × 多算法 × 较大 timesteps |
| 落盘续跑 | 非完整滚动产物主路径 | `artifacts/ashare_drl/`、`progress.json` |
| 耗时 | 相对短 | **很长**，不适合在网页里硬扛完整 99 窗 |
